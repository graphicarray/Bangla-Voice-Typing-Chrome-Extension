# Changelog

All notable changes to this project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/).

## [2.1.0] - 2026-10-30

### Added
- First public release on GitHub.
- Hold `Alt + C` to dictate, release to type.
- Floating mic button with recording and processing states.
- Gemini-powered Bangla transcription with automatic punctuation and filler removal.
- Spoken punctuation commands (দাঁড়ি, কমা, প্রশ্নচিহ্ন, বিস্ময়চিহ্ন, নতুন লাইন, নতুন অনুচ্ছেদ).
- Options for Bangla digits, keeping English words in English, and showing or hiding the mic button.
- Model picker that loads available Gemini models from your API key.
- Google Docs support through its hidden input frame.
- Quiet-voice gain boost and 16 kHz mono WAV conversion.
- Popup "Last transcript" with a Copy button.
